Available Endpoints Summary

POST /api/v1/auth/register Register a new user account
POST /api/v1/auth/login Authenticate user and obtain JWT token
GET /api/v1/tasks Retrieve user's task list (supports search & filters)
POST /api/v1/tasks Create a new task entity
PUT /api/v1/tasks/{id} Update task status, priority, or title
DELETE /api/v1/tasks/{id} Remove task from database
GET /api/v1/analytics/summary Fetch user task statistics
